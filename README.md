# Bank Marketing ML Platform

## Project Overview

The **Bank Marketing ML Platform** is an end-to-end machine learning application developed using the Bank Marketing dataset.

The project covers data validation, exploratory data analysis, machine learning, customer segmentation, time-series forecasting, API deployment, and a web application.

### Main Objectives

- Analyze bank marketing campaign data
- Predict term deposit subscription
- Segment customers using clustering
- Forecast customer volume and subscription rate
- Provide machine learning services through APIs
- Provide a user-friendly web application
- Store authenticated user prediction and forecast history
